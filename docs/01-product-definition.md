# 阶段一：产品定义

## 产品定位

**一句话描述**
> 帮助进阶训练者追踪渐进超负荷——在 3 分钟内完成训练记录，随时看到卧推、深蹲、硬拉的重量进步曲线，以及体重/体脂的长期趋势。

## 核心价值

记录数据不是目的，**看到自己在变强**才是目的。

| 功能层 | 价值层 |
|--------|--------|
| 记录卧推的重量和日期 | 让你确认自己在渐进超负荷 |
| 记录体重/体脂 | 让你看到身体成分在往目标方向变化 |
| 历史数据对比 | 让你在每次训练时知道要超越什么 |

## 目标用户

进阶训练者（详见用户研究）。

## 产品边界

### 做

- 训练数据记录（动作 / 重量 / 次数 / 组数）
- 三大项进步曲线（卧推 / 深蹲 / 硬拉）
- 身体数据记录与趋势（体重 / 体脂 / 肌肉含量）
- 一键复用上次训练
- 个人记录（PR）自动标记

### 不做

- 社交 / 分享 / 排行榜
- 饮食 / 热量追踪
- AI 训练建议
- 训练计时器
- 视频动作教学
