# 阶段八：测试上线

## A. 边界 / 异常测试清单

按 happy path 之外的场景逐项验证（真机为准）。

### 空 / 极少数据
- [ ] 全新账号打开曲线页：5 条曲线均显示「暂无数据」占位，不报错
- [ ] 训练列表为空：显示空状态引导文案
- [ ] 身体列表为空：显示空状态引导文案
- [ ] 某动作只有 1 次记录：曲线走单点分支（画点 + 数值），不画线
- [ ] 体脂只填体重不填：体脂曲线空、体重曲线正常

### 大数据量
- [ ] 录入 100+ 条训练：曲线页计算与渲染不卡顿
- [ ] 训练列表长列表滚动流畅
- [ ] 时间范围切到 ALL：数据点很多时折线仍可读

### 弱网 / 断网（核心兜底）
- [ ] 飞行模式下保存训练：UI 立即「已保存」，列表显示「待同步」
- [ ] 恢复网络：自动同步，「待同步」消失
- [ ] 断网保存后杀进程重进：队列仍在，联网后补同步
- [ ] 弱网下进曲线页：先显示缓存，不白屏

### 业务逻辑边界
- [ ] 主力工作组重量：同一动作多重量无众数并列时，取较重（如 50/55 各一组 → 55）
- [ ] 含 0 或空重量的组不计入主力工作组重量
- [ ] PR：连续创新高逐次标记；打平上次不算 PR
- [ ] 同一天记录两次不同分化（推/拉）：互不干扰，各自进对应曲线
- [ ] 删除训练后：曲线与 PR 重算正确
- [ ] 编辑训练改重量后：曲线随之更新

### 模板 / 动作库
- [ ] 首次进「新建训练」：自动播种推/拉/腿 3 套模板
- [ ] 改模板名称/动作后：新建训练用最新模板
- [ ] 删除模板后：引用过该模板的历史训练仍正常展示
- [ ] 自定义动作：在动作详情/库里能正确解析出名称（非 id）

### 单位
- [ ] kg→lb：历史数据显示换算正确，录入按 lb 步进（±5），曲线一致
- [ ] lb→kg：切回无精度损失（落库恒为 kg）

### 跨页一致性
- [ ] 任意页录入后返回曲线页/列表页：onShow 自动刷新，数据最新
- [ ] 点曲线进动作详情：单动作曲线 + 历史正确

## B. 上线检查表

### ⚠️ B0. 小程序备案（最大的现实门槛，先办）
- [ ] 完成**小程序 ICP 备案**（mp 后台 → 设置 → 基本设置 → 备案）
  - 自 2023.9 起微信要求小程序**备案通过后才能发布**，个人主体可办
  - 周期约几个工作日到 20 个工作日，**越早开始越好**，否则代码就绪也发不了
  - 备案期间可继续用体验版测试，不影响开发

### B1. 主体与基本信息
- [ ] 小程序名称（唯一、不侵权，「训记」需确认未被占用，被占用则备选名）
- [ ] 简介（≤120 字，见 C 节草稿）
- [ ] 服务类目（健康/运动健身相关；个人主体可选类目有限，注意核对是否需要资质）
- [ ] 图标 144×144 PNG

### B2. 隐私与合规
- [ ] 配置「用户隐私保护指引」（mp 后台 → 设置 → 用户隐私保护）
  - 本应用主要依赖云开发自动获取的 openid 做数据隔离，未主动采集头像/昵称/手机号
  - 如后续接入头像昵称等，需在此声明对应采集项

### B3. 发布前技术核对
- [ ] `app.js` 云环境 ID 正确（当前用 DYNAMIC_CURRENT_ENV 默认环境）
- [ ] 4 个集合安全规则均为「仅创建者可读写」
- [ ] 体验版全量回归一遍 A 节清单
- [ ] 基础库版本兼容性（project.config.json libVersion）

### B4. 提交审核
- [ ] 开发者工具「上传」→ 填版本号 + 项目备注
- [ ] mp 后台「版本管理」→ 提交审核（勾选对应类目/页面）
- [ ] 审核通过后「发布」（一般 1-3 个工作日）
