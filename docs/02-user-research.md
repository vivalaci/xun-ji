# 阶段二：用户研究

## 研究方式

开发者本人即目标用户，需求直接来源于多年训练经验，无需外部用户访谈。

## 用户画像

**核心用户：进阶训练者**

- 有系统训练经验，以三大项（卧推/深蹲/硬拉）为核心训练内容
- 目前没有顺手的数字化记录工具
- 清楚自己要追踪什么数据，不需要引导
- 训练目的明确：追踪渐进超负荷，验证自己在进步

## 核心痛点

| 痛点 | 说明 |
|------|------|
| 没有记录 | 目前未使用任何工具，进步全靠记忆 |
| 组间时间有限 | 休息 1-3 分钟，记录必须极快 |
| 想看到进步 | 需要直观的数据可视化，不是流水账 |

## 使用场景

| 场景 | 频率 | 需求 |
|------|------|------|
| 组间休息时记录刚做完的组 | 高频 | 速度第一，1-2 次点击完成 |
| 训练结束后统一填写 | 高频 | 能快速回顾并批量填入 |
| 非训练时查看进步曲线 | 中频 | 清晰的可视化，看到趋势 |
| 记录体重/体脂 | 低频 | 简单，想记就记，无需强制 |

## 关键约束

- **单次训练记录时间 ≤ 3 分钟**（5 个动作 × 4 组 = 20 组数据）
- **不强制用户节奏**：没有「开始训练」/「结束训练」的仪式感
- **首页是数据曲线**，不是欢迎页或今日摘要
