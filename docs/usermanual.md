# 训记 · 用户手册

> 面向进阶训练者的训练数据记录工具。微信小程序，无需注册，微信授权即用，数据存于你的微信云、仅你可见、跨设备同步。

---

## 一、整体结构

底部 4 个 Tab：

| Tab | 用途 |
|-----|------|
| **首页** | 训练日历 + 进步曲线 |
| **训练** | 记录每次训练、查看历史 |
| **身体** | 记录体重、体脂、腰围 |
| **我的** | 训练模板、动作库、设置 |

---

## 二、首页：训练日历 + 进步曲线

**顶部·训练日历**
- 月视图，练过的日子显示彩色圆点，不同训练类型颜色不同。
- 标题显示「本月训练 N 天」，‹ › 切换月份。
- 点某天可查看当天训练详情。

**下方·进步曲线**
- 默认展示卧推 / 深蹲 / 硬拉主力重量 + 身体趋势（体重/体脂/腰围）。
- **硬拉曲线**合并硬拉家族：硬拉 / 罗马尼亚硬拉 / 直腿硬拉（通常每次只练其一）；当日做了多个变式，取其中主力工作组重量的最大值。点硬拉曲线进硬拉详情，详情同样汇总三个变式，历史里标注每次是哪个变式。
- 时间范围：右上角切换 **1M**（近 1 个月）/ **3M**（近 3 个月）/ **6M**（近 6 个月）/ **ALL**（全部历史）。
- **长按曲线卡片**进入编辑模式，可调整顺序或删除；底部「+ 添加曲线」可追加任意动作的进步曲线（最多 2 条）。
- 点曲线进「动作详情」，查看完整历史与 PR 标记（🏆）。缺数据处断线。

## 三、记录力量训练

**训练 → 右下角「+」→ 选模板 → 录入**

1. **选模板**：在选模板页选今天的训练日，或选「空白训练」手动添加动作。选模板是独立一页——进了录入页点左上角返回，会**退回选模板页**（而非直接退出），方便改选。
2. **预填**：选过的模板会自动复用上一次的重量和次数。
3. **录入**：用 −/+ 步进调整重量（kg±2.5 / lb±5）和次数（±1），「+ 加一组」增加组数，左滑可删除某组。
4. **调整动作顺序**：每个动作右上角 ↑/↓ 可上移/下移（力量与有氧通用），组/时长数据随动作整体移动。
5. **临时切换单位**：动作名旁可临时切换 kg/lb 录入，不影响其他动作，保存自动换算。重量统一显示到 0.5（只现整数或 .5，如 45、45.5），lb 录入换算后同样取整到最近的 0.5kg。
6. **自重动作**：如引体向上，重量填额外负重，纯自重填 0 或留空。
7. 填完点「保存训练」。**只填了部分动作也没关系**——模板铺出的全部动作都会保存，没填的记为 0，下次打开数据都在。

## 四、记录有氧训练

**训练 → 「+」→ 选「有氧训练」模板**

支持室内/室外跑步、走路、椭圆机、单车（录时长 + 距离）；爬楼梯（录时长 + 层数）。保存后在训练列表和日历中显示，不参与力量统计。

---

## 五、记录身体数据

**身体 → 右下角「+」**

体重必填；体脂率、腰围选填。数据汇入首页身体趋势图。每条记录可查看、编辑、删除。

---

## 六、模板管理

**我的 → 训练模板管理**

内置多套预设模板，也可新建自己的训练日。进编辑页可增减动作、排序、重命名。删除模板不影响历史训练记录。「我的模板」分组**置顶**显示（排在三分化之前），存完一眼可见。

**把训练记录一键存为模板**：打开一条**已有**训练记录（训练列表点进去），内容区顶部有【保存模板】按钮，点它确认即把当前动作组合存为「我的模板」——只留动作与组数（不含重量/次数），名称自动加「（我的）」后缀（如「上肢A（我的）」）。新建训练时不显示该按钮。存出的就是普通自建模板，可在模板管理页删除、在模板编辑页改动作。

---

## 七、动作库

**我的 → 动作库**

内置 100 个常见动作，按肌群分类，支持搜索。可新增自定义动作；内置动作不可删除。

---

## 八、单位设置

**我的 → 设置 → 重量单位**：选 kg 或 lb，全 App 同步切换，底层数据始终存 kg。

---

## 九、个人记录（PR）

无需手动标记。保存训练后系统自动识别是否创历史最大重量，是则打 🏆。

---

## 十、常见问题

**Q：换手机后数据还在吗？** 数据存微信云，同一微信登录即恢复。

**Q：怎么加自定义曲线？** 首页底部「+ 添加曲线」，选动作即可，最多 2 条。

**Q：能删除某组数据吗？** 进训练详情编辑，可修改或删除任意组，保存生效。
