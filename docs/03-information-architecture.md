# 阶段三：信息架构

## 导航结构

4 个 Tab，无二级导航栏。

```
训记
├── 曲线（Tab 1 · 首页）
│   ├── 卧推 主力工作组重量曲线
│   ├── 深蹲 主力工作组重量曲线
│   ├── 硬拉 主力工作组重量曲线
│   ├── 体重趋势曲线
│   └── 体脂趋势曲线
│       └── → 点击任意曲线进入「动作详情页」
│
├── 训练（Tab 2）
│   ├── 训练列表页（历史记录，按日期倒序）
│   │   └── → 训练详情页（查看 / 编辑 / 删除）
│   └── 新建训练页（先选模板 → 快速录入）
│       ├── → 动作选择页（来自动作库）
│       └── → 组数录入（内联，不跳页）
│
├── 身体（Tab 3）
│   ├── 身体数据列表页（按日期倒序）
│   │   └── → 身体数据详情页（查看 / 编辑 / 删除）
│   └── 新建身体数据页
│
└── 我的（Tab 4）
    ├── 个人信息（昵称 / 头像）
    ├── 训练模板管理（预设推/拉/腿，可编辑名称+动作、可增删）
    │   └── → 模板编辑页
    ├── 动作库管理（查看内置 + 自定义动作）
    └── 设置（重量单位 · 体脂单位）
```

## 功能优先级

### Must Have（MVP）
- 动作库（内置含三大项核心动作 + 自定义）
- 训练模板（预设推/拉/腿，可编辑、可增删）
- 训练记录：选模板 → 动作 + 重量 + 次数 + 组数
- 按模板复用上一次同类训练数据（预填）
- 三大项进步曲线（按主力工作组重量）
- 体重 / 体脂趋势曲线
- 训练历史列表
- 身体数据记录

### Should Have
- 个人记录（PR）自动标记
- 单次训练容量统计
- 时间范围切换（1M / 3M / 6M / ALL）

### Could Have（后续版本）
- 自定义追踪其他动作的曲线
- 训练计划 / 周期规划
- 数据导出

### Won't Have
- 社交功能
- 饮食追踪
- AI 建议
