# 阶段五：视觉设计

## 设计基调

**干净轻量感**

白底，大量留白，数字和曲线突出。类似 Apple Health / Whoop 的风格。清爽、易读、不压迫。

---

## 色彩系统 ✅

### 基础色

| 用途 | 色值 |
|------|------|
| 页面背景 | `#FFFFFF` |
| 卡片背景 | `#F9FAFB` |
| 分割线 / 边框 | `#F3F4F6` |
| 主文字 | `#111827` |
| 次要文字 | `#6B7280` |
| 禁用 / 占位 | `#D1D5DB` |

### 强调色

| 用途 | 色值 |
|------|------|
| 强调色 | `#1D4ED8` |
| 强调色浅版 | `#EFF6FF` |

### 语义色

| 用途 | 色值 |
|------|------|
| 成功 / 进步 | `#10B981` |
| 警告 | `#F59E0B` |
| 危险 / 删除 | `#EF4444` |

### 曲线颜色

| 曲线 | 色值 |
|------|------|
| 卧推 | `#1D4ED8` |
| 深蹲 | `#7C3AED` |
| 硬拉 | `#0891B2` |
| 体重 | `#111827` |
| 体脂 | `#6B7280` |

### 使用原则

```
90% 黑白灰  +  8% 深蓝（强调）  +  2% 语义色（仅在必要时出现）
```

## 字体规范 ✅

系统字体（iOS: PingFang SC / Android: Noto Sans SC）

| 层级 | 用途 | 字号 | 字重 |
|------|------|------|------|
| Display | 曲线大数字、PR 数值 | 52rpx | 700 |
| Title | 页面标题、卡片主标题 | 36rpx | 600 |
| Body | 正文、动作名称 | 28rpx | 400 |
| Secondary | 标签、日期、提示文字 | 24rpx | 400 |
| Caption | 最小文字、单位 | 22rpx | 400 |

## 间距系统 ✅

基于 8rpx 网格：`8 · 16 · 24 · 32 · 48 · 64rpx`

| 场景 | 值 |
|------|-----|
| 页面左右边距 | 32rpx |
| 卡片内边距 | 32rpx |
| 卡片间距 | 16rpx |
| 行内元素间距 | 8 / 16rpx |

## 圆角系统 ✅

| 场景 | 值 |
|------|-----|
| 主卡片 | 24rpx |
| 输入框 / 小卡片 | 16rpx |
| 标签 / Tag | 8rpx |
| 圆形元素 | 50% |
