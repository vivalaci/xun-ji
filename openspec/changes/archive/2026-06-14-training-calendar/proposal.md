# Proposal: training-calendar

## Why

用户想直观看到"本月练了多少天、每天练的是哪几项"。现在只有一条按日期倒序的训练流水，缺少月维度的全局视图，无法一眼看出训练密度与分化节奏（推/拉/蹲/上肢/下肢）。

## What Changes

- 在「训练」列表页**顶部嵌入月视图日历**：当月 7×N 网格，标题区显示月份 + 上/下月切换 + **「本月训练 N 天」**。
- 每个有训练的日期格显示**按分化类型配色的小圆点**（推/拉/蹲/上肢/下肢/其他各一色）；一天多练显示多个圆点（上限 3 个，超出折叠）。
- **点击某天**：在日历下方展示当天训练详情（训练名 + 类型点），点条目跳转到该训练的编辑/详情页。
- 纯读 `workouts` 现有数据做可视化，**不新增集合、不改任何字段**（符合架构铁律 6）。

## Capabilities

### New Capabilities

- `training-calendar`: 训练月历可视化——按月聚合训练、分化类型配色标记、本月训练天数统计、点击某天看详情并跳转。

### Modified Capabilities

（无——训练列表页基础行为未被任何现有 spec 覆盖；本 change 仅在其顶部新增日历区，不改其列表/删除逻辑。）

## Impact

- `pages/workout/list`：顶部新增日历区（月网格 + 月切换 + 选中日详情）；列表/删除逻辑不变。
- 新增纯函数模块 `utils/calendar.js`（生成月网格、按日期聚合训练、分化类型分类与配色、统计训练天数），`tests/algo.test.js` 补用例。
- 数据：仅消费现有 `workouts`（`date` / `name` / `templateId`），无集合、无字段变更。
- 跳转复用现有 `pages/workout/edit?id=`，零新页面。
