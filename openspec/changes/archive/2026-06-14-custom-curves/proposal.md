# Proposal: custom-curves

## Why

曲线首页目前固定 5 条（三大项 + 体重/体脂），顺序写死。用户的辅项重点各不相同（如高位下拉、肩推），无法把自己关心的动作放上首页，也不能按自己的优先级排列曲线。

## What Changes

- 曲线首页支持**长按进入编辑模式**：上移/下移箭头调整曲线顺序；自定义曲线可删除。
- 首页底部新增**「+ 添加曲线」**：从动作库（内置 + 自建）任选动作，生成该动作的主力工作组重量曲线；上限 **2 条**，满后入口禁用并提示。
- 固定 5 条曲线（卧推/深蹲/硬拉/体重/体脂）**不可删除**，仅可排序。
- 自定义曲线颜色由固定调色板按槽位循环分配，用户不可选色。
- 曲线配置（顺序 + 自定义列表）持久化到**新集合 `user_prefs`**（单文档），经 `utils/db.js` 缓存优先读 + 本地先写管线，跨设备同步、离线可用。

## Capabilities

### New Capabilities

- `curve-customization`: 曲线首页的可定制能力——编辑模式（排序/删除）、添加自定义动作曲线（口径与上限）、配置持久化与跨设备同步。

### Modified Capabilities

（无——现有 specs 未覆盖曲线首页基础行为；本 change 不改动已有 spec 的需求。）

## Impact

- `pages/curve/curve`：CHARTS 从硬编码常量改为"固定定义 + 用户配置"合成；新增编辑模式 UI 与添加曲线面板。
- `utils/db.js`：新增 `user_prefs` 读写辅助（确保单文档存在、更新走队列）。
- 新增纯函数模块（曲线配置合成/排序/增删校验），`tests/algo.test.js` 补用例。
- **新集合 `user_prefs`**：需用户在云控制台创建，权限「仅创建者可读写」；README 建集合表更新。
- 动作详情页、PR、单位换算零改动（自定义曲线复用主力工作组重量口径与现有跳转）。
