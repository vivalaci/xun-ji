# template-management Delta

## ADDED Requirements

### Requirement: 保存力量训练保留全部动作
保存力量训练（`type` 非 cardio）时，系统 SHALL 保留页面上铺出的**全部动作及其全部组**，不得因某动作未填写而将其丢弃；未填写的重量/次数 SHALL 记为 0。保存后再次打开该记录 SHALL 完整呈现原有动作与组（未填项显示为 0）。系统 SHALL 仅在整个训练**没有任何一组填写了重量或次数**时拦截保存（提示填写）。0 重量组 SHALL NOT 影响主力工作组重量、PR、容量等聚合（既有口径忽略 0 重量）。

#### Scenario: 只填一个动作仍保留其余
- **WHEN** 用户选「推日」模板（含多个动作），只在「卧推」填了数据便保存
- **THEN** 记录落库时保留模板铺出的全部动作，未填动作的组重量/次数记为 0；再次打开该记录时全部动作与组都在，未填项显示 0

#### Scenario: 部分填写的组补 0
- **WHEN** 某动作有 3 个组，用户只填了第 1 组的重量与次数
- **THEN** 第 2、3 组以 0 重量、0 次数落库并在重开时显示为 0，不被丢弃

#### Scenario: 完全空白拦截
- **WHEN** 用户进入新建训练后未填写任何一组的重量或次数即点保存
- **THEN** 系统拦截并提示填写，不创建空记录

#### Scenario: 0 重量不污染聚合
- **WHEN** 某训练含未填（0 重量）的动作组
- **THEN** 该 0 重量组不计入任何动作的主力工作组重量、PR 判定与容量统计
