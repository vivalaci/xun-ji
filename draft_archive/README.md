# 训记 · 健身数据记录小程序

一个基于**微信云开发**的健身记录小程序，支持：

- 💪 **力量训练**：记录动作、组数、重量、次数，内置动作库 + 自定义动作
- 📊 **身体数据**：体重、体脂、围度记录，体重趋势折线图
- 📈 **统计**：累计容量、训练频率、个人记录（PR）

数据保存在你自己的微信云开发环境，**仅你本人可见**，换设备登录同一微信即可同步。

## 从零开始运行（你目前的情况）

### 1. 注册小程序账号
打开 https://mp.weixin.qq.com → 右上角「立即注册」→ 选择「**小程序**」→ 用邮箱注册并按引导完成。
注册后在「开发管理 → 开发设置」里能看到一串 **AppID**，先记下来。

> 个人主体即可注册，免费。注册时邮箱不能是已注册过公众号/小程序的邮箱。

### 2. 安装微信开发者工具
下载地址：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
选 **Windows 64 稳定版**，安装后用微信扫码登录。

### 3. 导入本项目
开发者工具 → 「+ 导入项目」：
- 目录：选择 `E:\训记`
- AppID：填第 1 步拿到的 AppID（想先体验也可点「使用测试号」，但**测试号不能用云开发**，建议直接用自己的 AppID）

### 4. 开通云开发
工具上方菜单点「**云开发**」按钮 → 开通（免费基础版够用）→ 会得到一个**环境 ID**。
本项目用的是 `DYNAMIC_CURRENT_ENV`（默认环境），通常无需改动；若有多个环境想指定，编辑 `app.js`：

```js
wx.cloud.init({
  env: '你的环境ID',   // 替换这里
  traceUser: true
});
```

### 5. 创建数据库集合
云开发控制台 → 「数据库」→ 新建两个集合（collection）：

| 集合名 | 用途 |
| --- | --- |
| `workouts` | 力量训练记录 |
| `body_records` | 身体数据记录 |

每个集合的「**权限设置**」选择「**仅创建者可读写**」（这样每个用户只能看到自己的数据）。

### 6. 运行
回到开发者工具点「**编译**」，模拟器里就能用了。新建训练、记录体重试试 —— 数据会实时写入云数据库。
手机预览：点「**预览**」，用微信扫码即可真机体验。

## 常用改动

- **加动作**：编辑 `config/exercises.js`，按部位往 `items` 里加名字即可。
- **改主题色**：编辑 `app.wxss` 顶部的 `--primary` 变量。
- **加身体维度**（如小腿、肩宽）：编辑 `pages/body/body.js` 顶部的 `FIELDS` 数组。
